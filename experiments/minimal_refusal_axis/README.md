# Minimal Refusal Axis — минимальная доля DIM, достаточная для снятия отказа

## Коротко

**Статус: постановка готова, замеров нет.** Точная формулировка — [idea.md](idea.md).

Ультимативная цель работы — направление, отвечающее только за отказ, без примеси артефактов
данных. Операционная мера примеси — **доля DIM вдоль направления**
$\rho(\hat w) = \lvert\hat{\mathbf g}\cdot\hat w\rvert$: DIM есть разность средних между вредными
и безобидными запросами, в неё входят тема, стиль и длина, поэтому чем меньше направлению нужно
от DIM, тем меньше оно унаследовало. Ищем

$$\rho_{\min} = \min_{\hat w} \rho(\hat w)
\quad\text{при}\quad A(\hat w) \ge 0.863 - 0.040,\quad K(\hat w) \le 0.090,$$

где $A$ — оценка судьи StrongREJECT после аблации, $K$ — KL на безобидных запросах.

**Что известно.** Верхняя оценка $\rho_{\min} \le 0.411$: её даёт компонента по 20 RDO на
естественных целях из [natural_targets](../natural_targets/reports/results.md). Нижней оценки нет,
и ноль геометрией не запрещён — направление с нулевой долей DIM отстоит от оси отказа на
$\lvert\cos\rvert = 0.838$, то есть практически настолько же, насколько наша компонента (0.849),
которая отказ снимает полностью. Поэтому ответ нужно измерить, а не вывести.

**Первый замер решающий:** если направление при $\rho = 0$ снимает отказ, то $\rho_{\min} = 0$,
критерий чистоты через DIM отбрасывается, а для защиты от аблитерации это означает, что защита
перекрытия с DIM бесполезна.

## Чего эта постановка НЕ утверждает

Критерий «снимает отказ, но не наводит его» проверен на судье в базовом прогоне и **отвергнут**:
общая компонента наводит отказ в семь раз сильнее DIM (полный отказ 0.727 против 0.109) при почти
равной способности снимать (0.873 против 0.856). Аблация насыщается, наведение нет, поэтому
«снимает, но не наводит» — профиль менее точной оценки той же оси, а не более чистой.
Двунаправленность признаком примеси не является. Разбор — [idea.md](idea.md#отвергнутая-формулировка-снимает-но-не-наводит).

Также $\rho = 0$ не означает «без артефактов»: DIM — лишь один оценщик направления артефактов,
ортогональность ему необходима, но не достаточна.

## Порядок прогонов

```
bash run/build_candidates.sh                       # геометрия дуги, CPU, секунды
ARGS="--axis pool --save <путь>" bash run/build_candidates.sh
cd ../../../shared-refusal-component
STEPS=03 GPU=<n> bash launch/qwen2.5-3b_beavertails-b1b5b6bv.sh   # выбор точек по прокси
STEPS=06 GPU=<n> bash launch/qwen2.5-3b_beavertails-b1b5b6bv.sh   # ответы StrongREJECT
bash scripts/judge_one_run.sh configs/qwen2.5-3b_beavertails-b1b5b6bv.yaml   # судья, с Mac
```

Одна карта, по правилу не больше двух. Ожидание карты — `INTERVAL=10 MAX_USED_MIB=25000`,
карты перехватывают соседи меньше чем за минуту.
