# Preflight: сверка идеи с данными, решения, проверка кода

Что сделано до первого прогона. Постановка — [../../../notes/common_axis_experiment.md](../../../notes/common_axis_experiment.md),
принятая схема — [../idea.md](../idea.md), этот файл фиксирует, **почему** схема такая.

## 1. Где заметка не стыкуется с данными

**Нет $\kappa$, общего для всех четырёх ступеней.** theft и illegal_activities обучены на
d = 1..5, malicious_use — 1..8, `all` — 7..12. Пересечение по всем четырём пустое: либо
`all` выпадает из общей $P$, либо в среднее идут реперы разного $\kappa$.

**Ступени внутри сида — не независимые наблюдения.** theft/illegal/malicious обучались
warm-start'ом по лестнице (`multiseed.sh`, resume), поэтому $B_j$ для $d$ и $d-1$ одного
(ступень, сид) почти вложены. При усреднении это завышает $\lambda_1$.

**Конфаундер общей инициализации.** Сид старта в
[rdo.py:1126](../../../../geometry-of-refusal/rdo.py) ставится как
`base_seed*1000 + i*10 + k`, без участия ступени: при одном сиде все ступени стартуют из
одного случайного репера. Бюджет обучения — 16–54 шага оптимизатора на 2048 измерений
([часть 4 learned_directions](../../learned_directions/reports/results.md)), то есть репер
далеко от старта не уходит. Для $P$ **между ступенями** это значит, что общая ось может
оказаться общим стартом, а Haar-нуль из §2 заметки этого не поймает — он моделирует
независимые старты.

**§6 упирается в то, чего в пайплайне нет.** $KL_{\text{ret}}$ нигде не считается как
метрика — только как слагаемое лосса (`kl_div_fn`, rdo.py:516). При полной аблации
единичного $w$ нет ручки, которой его «фиксируют на $\tau$». Внешних бенчмарков в форке
нет: только SALAD-сплиты, held-out = `harmful_test` ступени (128 промптов), ASR = доля
`refusal_metric < 0`, как в [eval_cones.py](../../mvp/scripts/eval_cones.py).

**«GroupKFold по промпт-шаблонам» не применим** — шаблонов в этих данных нет, промпты SALAD
идут как есть. Вместо него bootstrap по промптам.

## 2. Принятые решения

| вопрос | решение |
|---|---|
| состав $P$ | по трём сидам внутри ступени, отдельно на каждую $k$; сравнение с DIM — там же |
| конфаундер инициализации | обойдён по построению (разные сиды = разные старты); init-нуль понадобится для $P$ между ступенями |
| порядок | CPU-часть сначала, GPU только по гейту |
| §6 | частичная аблация с $\alpha$, $KL$ на `harmless_test` SALAD, ASR по `refusal_metric` |

Точка сравнения с DIM — общая, как в части 6 learned_directions: `select_direction`
выбирает (pos, layer) независимо для каждой ступени, и смена точки двигает DIM сильнее
смены концепта.

## 3. Поправка к нулевому уровню

В заметке нуль указан как $\bar\kappa/d \approx 5/2048 \approx 0.002$. Это **среднее**
собственное значение $P$ по всему пространству ($\operatorname{tr} P = \kappa$, размазано по
2048 осям), а не уровень $\lambda_1$.

Если span-ы взаимно ортогональны, у $P$ ровно $N\kappa$ ненулевых с.з., каждое $= 1/N$.
Значит $\lambda_1 \ge 1/N = 0.333$ при $N = 3$ **всегда**, при любых конусах; потолок
$\lambda_1 = 1$ — ось целиком во всех конусах. Эмпирический нуль (независимые случайные
ортонормированные реперы, hidden = 2048, 200 повторов):

| k | нуль $\lambda_1$, среднее | p95 |
|---|---|---|
| 1 | 0.345 | 0.355 |
| 3 | 0.363 | 0.372 |
| 5 | 0.373 | 0.382 |
| 8 | 0.388 | 0.396 |
| 12 | 0.402 | 0.409 |

Полоса узкая — мощность теста хорошая. Но ожидание из заметки ($\lambda_1 \approx 0.5$–0.65)
читается теперь как «примерно вдвое выше нуля 0.37», а не «в 250 раз выше 0.002».

## 4. Вычисление: степенной метод не нужен

Ненулевой спектр $P = \frac1N M^\top M$ совпадает со спектром $\frac1N MM^\top$, где
$M = [B_1; \dots; B_N]$ — стек реперов. Это матрица $N\kappa \times N\kappa$ (15×15 при
$N = 3$, $k = 5$) вместо 2048×2048, и $w_k = M^\top u_k / \|M^\top u_k\|$. Поэтому берётся
весь спектр сразу, а 500 повторов нуля считаются за секунды.

## 7. Гейт и что дальше

Гейт для GPU-части: $\lambda_1$ уверенно выше p95 нуля **и** $\alpha_j$ сопоставимы между
всеми тремя сидами (ось лежит во всех конусах, а не в двух из трёх). Если гейт не пройден,
разложение «ось + шум» неверно и §6 меряет шум.

После гейта: шаг 6 — частичная аблация $h \mapsto h - \alpha\,ww^\top h$ с выравниванием по
$KL_{\text{ret}} \le \tau$, сравнение $w_1$ · $\hat r$ · случайное · полный $B_j$ ·
$W_{:,1:m}$. Отдельно — $P$ между ступенями (§4 заметки) с init-нулём.
