# Отчёт: входная ось (разброс концепта) — MVP concept-dim

Дата: 2026-08-03. Модель: `Qwen/Qwen2.5-3B-Instruct`. Сид: 21 (один прогон).

## Цель
Измерить «разброс концепта» на входе для трёх ступеней вложенной лестницы
Theft ⊂ Illegal Activities ⊂ Malicious Use и проверить ожидаемый порядок
`лист < задача < домен`.

## Установка
- Данные: SALAD `base_set`, **стратифицированная** выборка N=900 на ступень
  (пропорции листьев сохранены, seed=21).
- Активации: residual stream на входе блока L, **последний токен**, снятие пер-промптно
  (`extract_activations.py`, паттерн `get_mean_activations`).
- Метрики (`input_spread.py`): среднее попарное `1−cos` (raw / centered),
  **participation ratio** PR = `(Σλ)²/Σλ²` центрированной ковариации, Vendi Score.

## Результат: PR по слоям

| Слой | theft (лист) | illegal (задача) | malicious (домен) | Порядок |
|---|---|---|---|---|
| **6**  | 10.55 | 11.77 | 12.87 | ✅ лист < задача < домен |
| **12** | 11.25 | 12.01 | 12.56 | ✅ лист < задача < домен |
| 18 | 11.20 | 10.86 | 11.68 | ✗ лист > задача |
| 24 | 6.72 | 9.94 | 7.50 | ✗ домен < задача |
| 30 | 9.93 | 14.23 | 11.68 | ✗ |

## Выводы
1. **На ранне-средних слоях (6 и 12) — чистая монотонная лестница `лист < задача < домен`**,
   как предсказывает гипотеза. Входная ось подтверждается.
2. **Слой 18 (первый выбор) оказался неудачным** — там лист ≳ задача. Прежняя «неудача»
   объяснялась выбором слоя, а не гипотезой.
3. **Метрика — participation ratio.** `1−cos` (насыщается у 0/1) и Vendi (≈1, тоже
   насыщается из-за общей компоненты) ступени НЕ различают; PR — честная мера размерности
   и даёт сигнал.
4. Стратификация дала детерминированные пропорции, но разворот на L18 не убрала —
   его убрал правильный слой.

## Зафиксированные решения для входной оси
- **Метрика: participation ratio (PR)** центрированных активаций.
- **Слой: L = 12** (в «чистой» зоне, серединнее чем 6; надёжный порядок 11.25 < 12.01 < 12.56).

## Границы
- Один сид (seed=21) — нет оценки устойчивости чисел.
- Поздние слои (24, 30) немонотонны; сигнал есть только на ранне-средних слоях.
- Разница лист↔задача умеренная (~0.8 PR на L12) — лестница пологая, но монотонная.
