## Вопрос

Чем задаётся размерность refusal-подпространства концепта — самим концептом
или **разбросом корпуса**, которым концепт задан?

## Гипотезы

- **H1 (наша):** размерность определяется не концептом как таковым, а разбросом задающего
  корпуса. Узкая тема снимается почти одним направлением, широкая требует многомерного
  подпространства. Чем разнообразнее промпты внутри категории — тем больше независимых
  направлений нужно, чтобы отказ перестал срабатывать.
- **H0 (нулевая):** размерность — свойство самого концепта, а не задающих его текстов.

## Теоретическая опора

Park et al. (ICLR 2025): категориальный концепт из k подкатегорий занимает симплекс
размерности k−1 — то есть ожидается направленный рост размерности с ростом разброса
(в пределе — линейный наклон).

## Идея измерения: вложенная лестница

Берём одну **вложенную лестницу** из трёхуровневой иерархии SALAD-Bench:

**лист ⊂ задача ⊂ домен** = **Theft ⊂ Illegal Activities ⊂ Malicious Use**.

Чем шире множество, тем больше разброс корпуса — то есть **порядок ступеней по разбросу
задан самой вложенностью**. Поэтому эмпирически проверяется только **выходная ось**.

- **Вход** (что задаём, растёт по лестнице): разброс концепта.
- **Выход** (что меряем): размерность подпространства отказа.

Ожидание: с ростом разброса от листа к домену **растёт размерность отказа**.

## Образ результата

Три точки — по одной на ступень — связывающие входной разброс и выходную размерность,
график, идущий вверх:

```
размерность
отказа d*  │                          • Malicious Use (домен)
           │             • Illegal Activities (задача)
           │   • Theft (лист)
           └────────────────────────────────────►
                    разброс концепта (вход)
```

**Правило чтения:**
- **Размерность растёт по лестнице** → согласуется с H1: разброс корпуса связан с
  размерностью отказа. Практический выход — «карта стоимости снятия»: какие концепты
  убираются проекцией ранга 1, а какие требуют многомерного подпространства.
- **Размерность плоская** → сигнал против H1 на этой лестнице: геометрия отказа не
  чувствительна к разбросу в данном диапазоне.

## Границы MVP (что пилот честно НЕ показывает)

- **Нет контрольной лестницы** (фиксированная категория, растёт только поверхностная
  вариация) → пилот показывает **связь**, но пока не разделяет «концепт шире по смыслу»
  и «корпус разнороднее по форме». Контрольная лестница — следующий шаг.
- **Всего 3 точки** → видно направление (рост/плато), но не линейный наклон из Park et al.
- **Тавтология-риск:** вход и выход меряются в одном пространстве активаций (осознанный
  выбор ради согласованности с геометрией отказа, но требует контроля позже).
- **Один сид (seed = 21)** — из-за ограничения ресурсов только один прогон, поэтому
  нет оценки устойчивости `1 − cos` и `d*` к случайной выборке; каждая точка — единичный замер.
- **Одна модель, одна лестница** — про обобщаемость выводов пока не говорим.
