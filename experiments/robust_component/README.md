# Robust Component — взвешенные и робастные оценки общей компоненты

## Коротко

Проверяем, можно ли получить более чистую общую компоненту отказа из тех же 24 векторов
(4 DIM + 20 RDO, запуск `qwen2.5-3b_salad-o1o2o5o6` в shared-refusal-component), если
вместо обычного собственного вектора с равными весами взвешивать векторы по их общей части
или использовать робастную оценку оси. Мерило — k из split-half: ρ² = 1/(1 + k/N).

**Не даёт.** На независимых векторах (только 20 RDO) все оценки совпадают с PCA в пределах
шума (k 1.76–1.85 против 1.76 у PCA). На полном пуле взвешенные и робастные оценки хуже
(k 1.73–1.92 против 1.71): они принимают согласие четырёх почти одинаковых DIM за чистоту.
Причина — PCA уже сам умножает каждый вектор на его общую часть, поэтому векторы без общей
части (сиды s08, s12, s18) в его ось почти не входят; выбрасывать их не нужно. Чистоту
компоненты ограничивает доля общей части в каждом векторе (c² ≈ 0.37), а не способ
усреднения: при том же N чище будет только с лучшими векторами.

**Итог: текущий метод (PCA с равными весами по всем векторам) оставляем.**
