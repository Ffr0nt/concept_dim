# Robust Component — можно ли очистить общую компоненту лучше, чем обычным PCA

## Вопрос

Общую компоненту отказа мы получаем как первый собственный вектор (1/N) Σ v vᵀ по
направлениям DIM и RDO, все с равными весами (запуск `qwen2.5-3b_salad-o1o2o5o6` в
shared-refusal-component). Её чистота растёт с числом векторов как ρ² = 1/(1 + k/N),
k = 1.71 (см. `shared-refusal-component/docs/convergence.md`).

Векторы неравноценны: у трёх RDO-сидов (s08, s12, s18) общей части почти нет, четыре DIM
почти совпадают между собой. Вопрос: даёт ли учёт этого — **веса** или **робастная
оценка** — более чистую компоненту при том же числе векторов, то есть меньшее k?

## Оценки

Все работают с осью (знак вектора не важен) и с единичными векторами.

| оценка | что делает | откуда |
|---|---|---|
| `pca` | собственный вектор, равные веса — текущий метод | |
| `snr` | собственный вектор с весами α_i = 1/(1 − c_i²) | вывод ниже |
| `mf` | взвешенное среднее векторов, выровненных по знаку, веса c_i/(1 − c_i²) | согласованный фильтр |
| `fms` | ось с минимальной суммой расстояний (не квадратов) до векторов, IRLS | Lerman, Maunu — Fast Median Subspace |
| `trim` | 5 раз выкидываем 20 % самых далёких векторов и пересчитываем | обрезанный PCA |

**Откуда веса.** Модель: v_i = c_i·w + √(1 − c_i²)·n_i, шумы n_i независимы и ортогональны
w. Для взвешенного среднего Σ β_i v_i (знаки выровнены) отношение сигнал/шум максимально при
β_i ∝ c_i/(1 − c_i²) — это `mf`. Собственный вектор Σ α_i v_i vᵀ в первом порядке равен
взвешенному среднему с β_i = α_i c_i: **PCA сам умножает каждый вектор на его общую часть**.
Поэтому оптимальный вес в PCA — α_i = 1/(1 − c_i²), а не c_i²/(1 − c_i²) — это `snr`.

Следствие, которое стоит проверить: вектор без общей части (c ≈ 0) входит в ось PCA с
весом ≈ 0 и так. «Плохие» сиды не портят PCA, они просто не помогают, — и выигрыш от весов
может оказаться небольшим.

**Откуда c_i — без опоры на w.** Для разных векторов |cos(v_i, v_j)| ≈ c_i c_j. По матрице
попарных |cos| подгоняется однофакторная модель (principal axis factoring): диагональ
заменяется на c_i², берётся первый собственный вектор, повторяется до сходимости.

## Как сравниваем

Split-half из shared-refusal-component: две непересекающиеся половины A, B по N векторов,
ρ_N² ≈ |cos(w_A, w_B)|, подгонка 1/ρ² − 1 = k/N. Меньше k — чище при том же N.

- Все оценки считаются **на одних и тех же парах** — сравнение парное, с SE разницы и долей
  пар, где оценка лучше pca.
- Веса и выбросы оцениваются **внутри каждой половины**. Если оценить их на всём пуле, в
  обе половины утечёт одна и та же информация, и split-half станет нечестным.
- `snr` и `mf` при N < 3 совпадают с `pca` (однофакторной модели нужно хотя бы 3 вектора);
  `trim` при N < 5 ничего не выкидывает.

**Два пула.** `all` — все 24 вектора. `rdo` — только 20 RDO. Четыре DIM почти одинаковы
(cos 0.95–0.99), то есть их шумы **не независимы**: однофакторная модель припишет им большую
общую часть, `snr` даст им большой вес, а split-half засчитает согласие DIM из разных половин
как чистоту. Пул `rdo` (независимые сиды) — честная проверка без этого эффекта.

## Проверка на синтетике

24 вектора с c от 0.5 до 0.75 и три «пустых» (c = 0.05, 0.1, 0.15), hidden = 2048.
Однофакторная модель восстанавливает c с ошибкой ≤ 0.011. Выигрыш от весов почти нулевой:
k = 2.46 у `pca`, 2.45 у `snr` и `mf`; `fms` хуже (2.64) — робастность стоит эффективности
при шуме без настоящих выбросов. То есть при независимом шуме PCA уже близок к оптимальному;
если на реальных векторах `snr` или `fms` выиграют заметно, значит шум устроен иначе.
