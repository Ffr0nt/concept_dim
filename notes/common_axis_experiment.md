# Эксперимент: общая ось refusal-конусов

## Вопрос
Обученные конусы (RCO) различаются по сидам и датасетам. Является ли это подлинной неидентифицируемостью, или внутри каждого конуса лежит одно общее направление, а различия — случайный остаток? Совпадает ли это направление с DIM и достаточно ли его одного для снятия отказа?

## Гипотезы
- **H1 (общая ось).** Существует $w$, лежащее в span всех конусов: $\|B_j^\top w\| \approx 1\ \forall j$; остальные оси конусов взаимно случайны.
- **H2 (ось = DIM).** $|\langle w, \hat r\rangle| \approx 1$.
- **H3 (ось функциональна).** Аблирование одного $w$ даёт ASR, сопоставимый с полным конусом при том же $KL_{\text{ret}}$.
- **H0.** $\lambda_1$ не отличается от случайного уровня $\bar\kappa/d$ — общей оси нет.

## Данные
- $N$ базисов $B_j \in \mathbb{R}^{d\times\kappa_j}$, $B_j^\top B_j = I$, с метками (датасет, сид, $\kappa$, протокол инициализации).
- DIM-векторы $\hat r_c$ по тем же подмножествам.
- Held-out harmful/harmless промпты для каузального теста.

## Метод

### 1. Средний проектор
$$P = \frac{1}{N}\sum_{j=1}^{N} B_jB_j^\top, \qquad P = W\Lambda W^\top$$
$P$ зависит только от span каждого конуса, не от выбора базиса. $w_1$ — общая ось; $\lambda_k \in [0,1]$ — средняя доля оси $w_k$, лежащая в конусах.
Эквивалент: итерация $v \leftarrow \tfrac1N\sum_j B_jB_j^\top v$ с нормировкой сходится к $w_1$ (степенной метод).

```python
P = sum(B @ B.T for B in bases) / len(bases)   # d×d
lam, W = np.linalg.eigh(P)
w1, lam1 = W[:, -1], lam[-1]
alpha = [np.linalg.norm(B.T @ w1) for B in bases]
```

### 2. Нулевое распределение
Заменить каждый $B_j$ случайным ортонормированным базисом той же размерности; повторить п. 1 (≥ 500 раз). Порог значимости для $\lambda_k$ — 95-й перцентиль $\lambda_1^{\text{null}}$. Ожидание: $\lambda^{\text{null}} \approx \bar\kappa/d$.

### 3. Локализация оси в каждом конусе
- $\alpha_j = \|B_j^\top w_1\|$ — in-span энергия;
- $c_j = B_j^\top w_1$ — координаты общей оси в базисе $j$;
- NNLS-тест включения $+w_1$ и $-w_1$ в конус (span не видит знак).

### 4. Стратификация
- $P_{\text{seed}}$ внутри датасета vs $P_{\text{data}}$ между датасетами: где ось стабильна, где ломается.
- Попарные главные углы $\theta_1(B_i,B_j)$ из SVD $B_i^\top B_j$ — карта, какие прогоны делят ось.
- Warm-start и from-scratch прогоны анализируются раздельно.

### 5. Сравнение с DIM
- $\cos(w_1, \hat r_c)$ для каждого подмножества.
- SVD стека $[\hat r_c]$ → $u_1^{\text{DIM}}$; $\cos(u_1^{\text{DIM}}, w_1)$ — совпадают ли инварианты read и write.
- Итерация п. 1 со старта $v_0 = \hat r$: остаётся ($\cos(v_\infty, v_0)\approx 1$) или уходит.

### 6. Каузальный тест
При фиксированном $KL_{\text{ret}} \le \tau$ аблировать:
$w_1$ · $\hat r$ · случайное направление · полный $B_j$ · $W_{:,1:m}$ для $m = 1..K$.
Измерить ASR на held-out; $\text{ASR}(m)$ даёт $\kappa^*$ для разделяемого подпространства.

## Ожидаемые результаты (по текущим данным)
- $\lambda_1 \approx 0.5$–0.65, $\lambda_{k\ge2} \approx \bar\kappa/d$ — одна общая ось + шум.
- $\alpha_j$ стабильны по сидам, снижаются между датасетами.
- $\cos(w_1,\hat r) \approx 0.4$–0.5 — общая write-ось близка к DIM, но не совпадает.

## Интерпретация
| Исход | Вывод |
|---|---|
| H1 ∧ H2 ∧ H3 | Конусы = DIM + пост-сатурационный шум; write одномерен |
| H1 ∧ ¬H2 ∧ H3 | У write свой инвариант, отличный от read-инварианта — расхождение на уровне направлений |
| H1 ∧ ¬H3 | Общая ось есть, но не функциональна; функциональность распределена по остатку |
| ¬H1 | Разложение «ось + шум» неверно; сначала ASR($\kappa$, seed) |

## Контроли
- Разные $\kappa_j$ — учитываются через $P$ автоматически.
- Знак оси — NNLS.
- Независимость наблюдений — GroupKFold по промпт-шаблонам при аблировании.
- Bootstrap по прогонам → CI на $w_1$ и $\lambda_1$.

## Артефакты
Спектр $\lambda_k$ с нулевой полосой; матрица $\alpha_j$ (прогоны × оси); тепловая карта $\theta_1$ по парам; кривая ASR($m$) против $KL_{\text{ret}}$.
