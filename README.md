Проект.

## Окружение и работа на сервере

Разработка ведётся локально, тяжёлые вычисления — на Cloud.ru ML Space
(инстанс с GPU H100). Рабочая папка на сервере: `~/f.zakharov`.

Правила подключения и рабочего процесса см. в родительской папке:
`../SSH-WORKFLOW.md` и `../README.md`.

## Схема работы через git

1. Пишем и коммитим локально → `git push`.
2. На сервере внутри `~/f.zakharov` делаем `git clone` / `git pull`.
3. Тяжёлые и любые GPU-задачи запускает пользователь вручную.
4. Большие артефакты (веса, датасеты, логи) в git не храним — см. `.gitignore`.
